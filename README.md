# Quiz Game | 知识问答

## 项目简介
基于 HTML/CSS/JavaScript 实现的知识问答游戏，包含10道Web前端相关题目。

## 功能特性
- 🧠 10道前端知识题（HTML/CSS/JS）
- 📊 实时进度条和得分显示
- ✅ 即时反馈正确/错误答案
- 🏆 结果统计和评级
- ⌨️ 键盘快捷键（1-4选答案，Enter下一题）
- 📱 响应式设计
- 🔄 支持重新开始

## 技术栈
- HTML5
- CSS3（Flexbox、动画、响应式）
- JavaScript（ES6+，状态管理，DOM操作）

## 文件结构

quiz-game/

直接在浏览器中打开 `index.html` 即可。
